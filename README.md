# CSOPESY MO1

Current C++ console operating-system simulation project for CSOPESY.

## Open and run

1. Open `MO1Project.slnx` in Visual Studio with the C++ desktop development workload, the Windows SDK, and the v145 C++ toolset.
2. Build and run `MO1Project` (the project uses C++20).
3. Keep `MO1Project/config.txt` in the program's working directory. The program reads `config.txt` from the current directory.
4. Enter `initialize` to load the configuration. Enter `exit` to quit.

This is a snapshot of work in progress. The original source and Visual Studio project files are included unchanged; local settings and generated build files are excluded.
